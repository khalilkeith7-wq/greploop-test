# Release Checklist

Owned by Release Archivist. All items must pass before ship.

- [ ] Task board shows no open blockers for release scope
- [ ] Evaluation Scientist verification evidence attached or linked
- [ ] Tests and CI checks pass
- [ ] Security review complete for auth, secrets, shell, and dependencies
- [ ] Documentation and ADRs updated in `.agents/decisions.md` or project docs
- [ ] Handoff log contains final release summary
- [ ] Greploop run complete if a PR/MR is involved (5/5, zero unresolved)
